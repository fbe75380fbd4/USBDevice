# Changelog

## 0.0.1

- Added the `Get-USBDevice` cmdlet for inspecting connected USB devices.
- Added the `Get-USBPort` cmdlet for inspecting USB hub ports.
- Added a platform check to prevent importing the module on non-Windows systems.
- Added filtering options to both cmdlets.
- Added default table formatting for USB port results.
- Added external help documentation for both cmdlets.
